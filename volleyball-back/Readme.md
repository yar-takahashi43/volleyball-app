# volleyball-back

Express API。

## 起動

```bash
cp .env.example .env
# MONGOURL / JWT_SECRET / CLIENT_ORIGIN を編集
npm install
npm run dev    # 開発（nodemon）
npm start      # 本番相当（node server.js）
```

環境変数の説明は `.env.example` とルート `Readme.md`、本番手順は `memo/ai/phase8/task-9-release-deploy-2026-11-22.md` を参照。
